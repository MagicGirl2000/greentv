## 一、项目是什么

一套**跨境双端**的“全球电视频道维度检测”系统：

```
深圳本地数据中心            英国·伦敦服务器(8.208.127.130)
  采样 + 显卡解码分析   ⇄    聚合展示 / 对外网站 / 按需点播
  本地 AI(小七/Adam)         加密代理(英国IP下载国际源)
```

把全球电视频道的**音频+画面**实时映射成虚构的“维度”，聚合成 Gate 风格红绿白蜡烛的
**绿太阳指数**（绿涨/红跌/白平），配世界地图、省级降雨四色、卫星云图、天气一致性校验。

## 二、核心技术（全部对应真实源码，可逐行复核）

### 1. 维度检测算法（`feat.py` / `dimension.py`）
- **感知指纹**：音频 @11025Hz → STFT(1024/512,Hann) → 取前320频点 → 24个对数频带 →
  `log1p` → **L2 归一化** = 每段约 0.5s 的 **24 维单位向量**（不可逆，给字典也还原不出音频）。
- **哈希比对**：实时段向量 `v` 与字典矩阵 `V` 做 `s = V @ v`（双方单位向量，点积即**余弦相似度**），
  `argmax` 取最近邻 → 读该段维度标签 → 整段取中位数定维度、均值定置信度。
- **视频融合**：抽帧 64×36，按亮度+饱和度映射维度，与音频按 `0.6:0.4` 融合。

### 2. 跨境加密链路（`link.py`）
- `SHA-256(口令)` 派生 → **Fernet（AES-128-CBC + HMAC-SHA256 + 时间戳）**；
- 口令不对/被篡改 → `InvalidToken` 直接拒；
- **指纹校验**：`SHA-256(口令)[:8]` 两端比对，确认同钥而不泄露口令本身。
- 只传“维度数字/元数据”，不传任何直播内容。

### 3. 本地 AI（Ollama）
- **小七(Adam) = qwen2.5-coder:7b**（日常、离线、私密），**老师 = qwen2.5-coder:32b**（深度）；
- `server.py` 的 `/api/chat` 分支：本地 Ollama → Anthropic → 本地兜底；
- `adam_gateway.py`/`adam_client.py`：英国经 link 加密调深圳本地模型。

### 4. 真·本地微调（QLoRA，`train/`）
- **8GB 显存(RTX 3070)** 上 **QLoRA 4-bit** 微调小七的 LoRA：batch=1 + 梯度累积 + 梯度检查点；
- **32b 当老师蒸馏**产出标准答案 → 训练 7b；
- **防坍缩**：留出验证集算 `eval_loss`，**只有变好才更新 `out/best`**，原始模型永不被改、可回滚；
- **持续循环**(`train_loop.py`)：产数据→微调→留最优→再来；训练前自动卸载 Ollama 显存防 OOM。
- **上线**(`promote_gguf.py`)：合并 LoRA → 转 GGUF → `ollama create xiaoqi:trained`。

### 5. 跨境加密遥控训练（`train/`，3.5x 通讯升级）
- 深圳在 NAT 后，用英国公网做**加密信箱**集合点：
  `网吧端 cafe_client → 英国 uk_train_mailbox → 深圳 train_control 轮询执行 → 回传进度`，
  全程 link 加密；网吧端口令走环境变量、不落地。可远程 `start/pause/stop/watch`。

### 6. 加密源码回传（`uksync/`）
- 英国端**专职打包服务**：收加密指令 → 打包源码 → **双层加密**回传深圳
  （传输层 Fernet + 落地层 zip AES-256 密码）→ SHA-256 端到端校验。
- **只打包，不执行任意命令**（非远程执行后门）。已编译为带管理员声明的
  `打包源码加密传输至深圳.exe`。

## 四、设计理念（三态平衡）

系统以“**三魔女平衡**”为内核（虚构设定）：
- 🟢 **解放/力**（绿）——给出能力与增长；
- 🔴 **秩序**（红）——立规矩（如训练 `eval` 防坍缩，练崩不许上线）；
- ⚫ **平衡**（黑）——调度，不让任一极失控。

力量先以进取的姿态降世，被秩序与平衡磨过，方为可用之“器”。技术之于高维之理，
恰如《易经》“形而上者谓之道，形而下者谓之器”——**器是道（法力）在人间的外显**；
而《道德经》“大象无形、大音希声”，也正合“越高维越隐蔽”之意。**仅为创作世界观，博君一笑。**
