============================================================
 深圳⇄英国 加密通道 · 英国源码加密回传  (3.5109)
============================================================
目的：深圳发一条加密指令 → 英国把全部源码打包 → 加密回传深圳数据中心。
原理：只做“打包+加密回传”一件事，不执行任何上传脚本/任意命令（非 RCE 后门）。
      口令泄露也只能下载源码，无法在英国机器上运行东西。

【两个文件】
  uk_pack_serve.py   英国端打包服务（部署到英国，:8796）
  sz_fetch_uk.py     深圳端加密拉取（本机一条命令，完成自动打印结果）

------------------------------------------------------------
⚠️ 关键：口令一致性（务必看）
------------------------------------------------------------
两端口令由 link.py 读取 link_key.txt（UTF-8）。指纹应为 32cf8711。
· 正确做法：两端各放一份**相同的 link_key.txt**，**不要**用 PowerShell/CMD 去
  `set GREENTV_KEY=...` ——Windows 控制台按 GBK 读取，含非 ASCII 的口令会被读歪，
  导致两端指纹不一致（如错成 55bff07d）→ 一律 403。
· 自检：两端各跑  python -c "import link; print(link.key_fingerprint())"
  必须都打印 32cf8711 才通。

------------------------------------------------------------
一、英国端部署（RDP 一次）
------------------------------------------------------------
1) 把 link.py + link_key.txt + uk_pack_serve.py 放英国 greentv 目录
2) 装密码 zip 依赖：pip install pyzipper
3) 设 zip 密码（二选一，均不进源码/不外泄，密码自定、勿写进文档/仓库）：
     · 在 uksync 目录放 zip_pwd.txt，内容一行：<你设定的压缩密码>   （已 gitignore）
     · 或设环境变量 GREENTV_ZIP_PWD=<你设定的压缩密码>
4) python uk_pack_serve.py        # 默认打包其上级 greentv 目录，监听 :8796
5) 阿里云安全组放行 TCP 8796
   （打包自动排除 .git/__pycache__/dist/build/数据库/日志/模型/压缩包/zip_pwd.txt 等，
     只回传源码+配置+证书；>25MB 的单文件跳过）

【双层加密】
  · 传输层：link.py Fernet（AES-128-CBC+HMAC-SHA256），口令 link_key.txt
  · 落地层：源码 zip 本身 AES-256 加密，**打开需你设定的压缩密码**
  深圳端无需密码即可接收落盘；日后解压该 zip 时才需输入你设定的压缩密码。

------------------------------------------------------------
二、深圳端拉取（本机一条命令）
------------------------------------------------------------
   cd D:\ballbs\greentv\uksync
   python sz_fetch_uk.py
   （默认 GREENTV_UKSRC_URL=http://8.208.127.130:8796，
     落盘 GREENTV_UKSRC_DEST=D:\ballbs\英国源码备份）
   流程：ping 验指纹 → 发加密指令 → 英国打包 → Fernet 加密回传 →
        SHA-256 校验 → 落盘 → 打印“完成 哈哈”。

------------------------------------------------------------
三、加密说明
------------------------------------------------------------
   全程 link.py：SHA-256(口令) 派生 → Fernet(AES-128-CBC + HMAC-SHA256)。
   zip 经 base64 装进密文回传；SHA-256 端到端校验完整性。
